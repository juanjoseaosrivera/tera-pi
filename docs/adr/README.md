# Architecture Decision Records (ADR)

Cada ADR registra una decisión técnica importante: el contexto, las opciones que se valoraron, lo que se decidió y sus consecuencias. Un ADR aceptado no se edita para cambiar la decisión: si cambia, se escribe uno nuevo que lo sustituye.

**Estados:** Propuesto → Aceptado → (Sustituido por ADR-XXX | Obsoleto)
